# Archivi chiusura trimestre (locale)

I ZIP generati da `npm run finance:quarter-closure` restano qui sul Mac e **non** vanno in git.

Esempio:

```bash
npm run finance:quarter-closure -- --year=2026 --quarter=3
```

Vedi `docs/BACKUP_RESTORE_NEON.md` e `docs/DIAGNOSI_ACCESSI_FINANCE_2026-09-17.md`.
